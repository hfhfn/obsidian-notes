# 掘金头条项目实战
- 项目概况与环境搭建
  - 技术选型
    - FastAPI (高性能/异步IO)
    - SQLAlchemy (异步ORM)
    - Redis (高性能缓存)
    - Vue3 + Vite (前端)
  - 项目架构
    - 分层架构 (Models/Routers/CRUD/Schemas)
    - 前后端分离
    - MySQL 持久化存储
  - 环境配置
    - Python 3.12 虚拟环境
    - Node.js 依赖管理
    - aiomysql 异步驱动
- FastAPI 核心功能
  - 路由系统
    - APIRouter 模块化
    - HTTP 方法 (GET/POST/PUT/DELETE)
  - 请求参数
    - 路径参数与查询参数
    - Pydantic 模型请求体
    - Header 与 Cookie
  - 响应处理
    - JSONResponse 标准响应
    - Unified Data Format (Code/Msg/Data)
    - HTTPException 异常捕获
  - 中间件与依赖注入
    - CORS 跨域配置
    - Depends 业务逻辑抽取
- 数据库操作 (ORM)
  - SQLAlchemy 2.0
    - Mapped 类型注解
    - Async Session 上下文管理
  - CRUD 实战
    - 单表查询与分页
    - 一对多关联查询 (Join)
    - 聚合、排序与模糊匹配
- 业务模块开发
  - 新闻模块
    - 分类获取
    - 列表分页筛选
    - 详情展示与浏览量自增
  - 用户模块
    - Passlib 密码哈希
    - UUID Token 认证体系
    - 个人信息维护
  - 交互模块
    - 收藏功能 (联合唯一约束)
    - 浏览历史 (自动记录/清理)
- 性能优化与部署
  - Redis 缓存策略
    - Cache-Aside 旁路缓存
    - 新闻列表与详情缓存
    - TTL 过期机制
  - 生产部署
    - Gunicorn + Uvicorn 组合
    - Nginx 反向代理
    - Worker 数量规划
  - 拓展方向
    - AI 大模型接口集成
    - 前端项目构建
