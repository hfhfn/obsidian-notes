# Agent Hook 深度教程
- 核心定義與價值
  - 強制性約束機制
  - 凌駕於提示詞與系統指令
  - 由智能體而非大模型觸發
  - 解決 AI 不遵守約定的穩定性問題
- 四大核心機制
  - 事件 (Event)
    - 觸發時機 (生命週期節點)
    - 示例: user prompt submit
  - 匹配條件 (Match)
    - 篩選需要處理的操作
    - 示例: 僅對命令行工具觸發
  - 處理器 (Processor)
    - 執行腳本 (Python/Nodejs)
    - AI 輔助代碼編寫
  - 最終決策 (Decision)
    - 阻止當前操作
    - 允許並繼續下一步
- 主流智能體支持對比
  - Cloud Code
    - 支持 31 個事件
    - Prompt Handler (調用一次 AI)
    - Agent Handler (派發子智能體)
  - Codex
    - 基礎 Hook 支持
    - 暫不具備內置 AI 處理器
  - Deepstick Harness
    - 插件化機制
    - 推薦使用橋接插件連接現有 Hook
- 應用場景
  - 動態安全檢查
  - 敏感文件權限控制
  - 對話開始前注入背景信息
  - 內容二次加工 (如去 AI 味)
  - 對話狀態存檔 (Checkpoint)
- 構建流程
  - 明確功能需求
  - 讓 AI 拆解規則與編寫腳本
  - 配置 hooks.json 文件
  - 針對性提示詞功能測試
