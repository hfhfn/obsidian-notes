🎭 三种平均模式对比

💡 为什么 Weighted 和 Micro 如此接近？

  • 🔬 数学证明：
    • • Weighted Recall = Σ(Recall_i × Support_i) / ΣSupport = Σ(TP_i/(TP_i+FN_i) × (TP_i+FN_i)) / ΣSupport = ΣTP_i / ΣSupport
    • • Micro Recall = ΣTP_i / (ΣTP_i + ΣFN_i) = ΣTP_i / ΣSupport（因为Support = TP+FN）
    • • 结论：Weighted Recall ≡ Micro Recall（数学上完全相等！）
  • 📊 Precision 为什么也很接近？
    • • Weighted Precision = Σ(TP_i/(TP_i+FP_i) × Support_i) / ΣSupport
    • • Micro Precision = ΣTP_i / (ΣTP_i + ΣFP_i)
    • • 在多分类中，这两个公式通常给出非常接近的结果（但不完全相等）
    • • 只有在极端的、特定的混淆模式下，差异才会稍微明显（但仍然很小）
  • 🎯 那么 Macro 的意义是什么？
    • • Macro：每个类别平等权重，对少数类的表现非常敏感
    • • Weighted/Micro：偏向样本多的类别，反映整体效果
    • • 试试"🔍少数类差"案例：类别3样本少且表现差 → Macro显著降低，但Weighted/Micro影响很小
    • • 实际应用：如果 Macro ≪ Weighted，说明少数类表现很差；如果关心所有类别，应优化少数类
  • 🔍 观察建议：
    • 1. 点击不同预设按钮，重点观察 Macro vs Weighted 的差异（这才是关键对比）
    • 2. "Weighted vs Micro 差异分析"区域会验证 Recall 始终为 0.000%
    • 3. Precision 和 F1 的差异通常也在 0.1% 以内，除非极端场景
