# ✍️ 面试题-模板

> [!abstract] 用法
> 这是单道面试题的**统一格式**。日常发题给我时，我会按此模板整理进对应主题文件。模板只是参考，格式可随题目灵活调整，但**保留分区结构**便于复习。

## 模板

```markdown
## Q3. 题目一句话

> [!question] 追问
> - 追问一
> - 追问二

**参考答案 / 解析**
- 核心结论 + 支撑论据

**我的思路**（若你提供过思路）
- 你的原始想法 / 存疑点

**一句话记忆**
> 便于考前快速过一遍的核心概括

---

## 相关笔记
- [[面试收集-MOC|面试收集 MOC]]
- [[相关主题笔记]]
```

## 字段说明

| 字段 | 作用 | 必填 |
|------|------|------|
| `> [!question]` 题面 | 优化后的题目 + 可能追问 | ✅ |
| 参考答案 / 解析 | 我优化后的要点式答案 | ✅ |
| 我的思路 | 你的原始思路 / 存疑点 | 仅当你有 |
| 一句话记忆 | 考前速记核心 | ✅ |
| 相关笔记 | 2-3 个双链跳转 | ✅ |

## 编号规则
- 每篇主题文件内按 `Q1 / Q2 / Q3...` 递增编号
- 新题追加到对应主题文件末尾即可
