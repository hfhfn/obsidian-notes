## 摘要

人工智能正从简单的对话工具转型为能够长时间独立执行复杂、多步骤任务的自主长程 
Agent。这一范式转变由先进的模型推理能力和成熟的 harness 
架构所驱动，后者提供了诸如文件系统交互和上下文压缩等核心工具包。在这些发展中，c
oding agent 
代表了最接近通用人工智能（AGI）的形态，因为编程是控制计算机系统的通用机制。此外
，构建这些先进的 Agent 需要独特的软件工程实践，特别是利用 tracing 
技术来监控不可见的决策过程，以及依靠强健的 memory 
系统来维护个性化的操作历史。最终，这一技术演进将用专用的任务管理界面取代标准的
对话框，无缝融合异步自动化与实时人类反馈。
