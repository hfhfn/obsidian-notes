# 境外有境：真实摄影 × 东方超现实极简版画（提示词教程卡）

## 摘要

一套**可直接复用的「真实摄影 × 东方超现实极简版画」出图提示词**。做出来的效果是：一张 3:4 竖版海报，上下一分为二——**上半张保留原照片**，下半张把同一张照片提炼成丝网印刷质感的东方极简版画，并配 2–4 字中文题字。

整套东西由四部分组成：一句核心提示词 + 一句"提升原创性"的追加指令 + 一张参数约束表 + 七类题材的创意方向参考，最后用一张"务必遵守"的禁则清单兜底。图 1–6 是成品示例（上实拍 / 下版画），图 7 是完整教程卡。

## 二、核心提示词（可直接复制使用）

```text
请根据我上传的真实照片，独立创作一张「真实摄影×东方超现实极简版画」艺术海报。
整体具有当代东方美学、国际独立艺术杂志、实验性艺术书与高级丝网印刷版画的
设计质感。不是简单将照片转成插画，而是提炼照片最有辨识度的主体、色彩与情绪，
重新构建具有诗意、超现实想象力和独特空间关系的艺术作品。
```

### ➕ 建议追加（提升原创性）

```text
本次请重点分析照片最独特的视觉元素，选择一种最适合的超现实表达方式，重新
创作下半部分版画。不要复刻之前作品的构图，不要机械增加圆形背景、四角线框或
装饰颗粒。主体整体保持较小尺度，增加大面积干净留白。中文题字根据本张照片
独立创作，确保准确。优先提升画面的原创性、精致度、诗意和高级艺术质感。
```

> 追加段是系列出图不"同质化"的关键：它同时压住了三件最容易翻车的事——**复刻构图**、**模板化装饰**（圆形背景 / 四角线框 / 颗粒）、**题字乱写**。

## 三、关键参数与要求

| 项目 | 要求 |
|---|---|
| 画幅结构 | 3:4 竖版，**上下严格 1:1 分区** |
| 上半部分 | 完整保留真实摄影（可轻微调色） |
| 下半部分 | 提炼核心元素，**重新创作、非复制构图** |
| 艺术手法 | 抽象、错位、消隐、重组、负空间等 |
| 色彩 | 提取照片主色：朱红/青灰、檀褐/炭黑、靛蓝/珊瑚粉、松绿/灰青等 |
| 中文题字 | 仅 **2–4 字**，清雅宋体 / 瘦金体 / 行书 |
| 辅助线条 | 可用极细局部线，不必每张都有 |

## 四、创作流程（四步生成法）

| 步骤 | 动作 | 要点 |
|---|---|---|
| 1 上传照片 | 选高质量的东方意境照片 | 建筑 / 花卉 / 树木 / 山水 / 人物 |
| 2 提炼元素 | 分析照片独特之处 | 找最有辨识度的主体、色彩与情绪 |
| 3 设定创意 | 确定超现实表现方式 | 残影、飘散、悬浮、渐隐、错位倒影等 |
| 4 生成海报 | 按提示词生成 | 得到"摄影 + 版画"的艺术海报 |

---

## 五、创意方向参考（按照片类型选）

| 题材 | 可用的超现实手法 |
|---|---|
| 建筑类 | 屋檐、斗拱、残影、空间重组 |
| 花卉类 | 枝条延伸、花瓣飘散、轻盈留白 |
| 秋景类 | 落叶动态、叙事小主体（如猫、鸟等） |
| 山水类 | 山峦悬浮、错位倒影、光影解构 |
| 森林雪景 | 渐隐层次、负形切片、寂静空灵 |
| 城市街景 | 建筑轮廓、透视线条、城市记忆 |
| 人物动物 | 缩小主体、融入广阔意境空间 |

## 七、注意事项（务必遵守）

- ✖ 不能改变上方照片的**核心主体**
- ✖ 不要画面满铺、元素堆砌
- ✖ 不要简单复制原图或套用模板
- ✖ 不要过度写实或普通插画画风
- ✖ 不要使用巨大图形或固定元素
- ✖ 不要廉价滤镜、强烈渐变
- ✖ 不要添加英文、编号、坐标
- ✖ 确保中文题字准确、简洁、有意境

---

## 附：一句话用法

把 **核心提示词 + 建议追加 + 参数表前四行（画幅 3:4 上下 1:1 / 上半保留实拍 / 下半重新创作 / 手法与色彩）** 拼在一起，再挑一条对应题材的创意方向，附上照片一起发给模型即可；出图前检查题字是否是 2–4 个准确的中文字。
