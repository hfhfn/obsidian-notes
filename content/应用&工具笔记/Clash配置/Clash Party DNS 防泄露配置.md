# Clash Party DNS 防泄露配置

> **核心结论**：在系统代理模式（非 TUN 模式）下，防止 DNS 泄露的关键在于：**开启 Fake-IP 并禁用通配符拦截**，同时**严格区分国内/国外 DNS 的职责**。

## 一、 核心参数配置清单

### 1.首先开启clash party界面中的 DNS覆写 功能

在 Clash Party 的“DNS 覆写”界面中，各个服务器选项的作用和推荐填法如下：

### 2. 虚假 IP 设置 (Fake-IP)
*   **增强模式 (enhanced-mode)**：必须选择 `fake-ip`。
*   **Fake-IP 过滤 (fake-ip-filter)**：黑名单**必须删掉 `"*"`**！如果第一条是 `"*"`，Fake-IP 模式就会失效，所有域名都会强制进行真实本地解析，导致直接暴露国内 DNS。
    *   *保留常用的例外即可，如：`+.lan`、`+.local`、`time.*.com` 等。

### 3. 四层 DNS 服务器解析逻辑
- **开启遵守规则选项**
- 不要把国内和国外的 DNS 混淆，严格按以下职责划分：

| 配置项 (按 UI 顺序)                              | 作用域                    | 推荐填写内容                                                            | 理由                                          |
| :----------------------------------------- | :--------------------- | :---------------------------------------------------------------- | :------------------------------------------ |
| **DNS 服务器域名解析**<br>`default-nameserver`    | 引导 DNS，解析其他 DoH 服务器的域名 | `tls://223.5.5.5`<br>`tls://1.1.1.1`<br>`tls://8.8.8.8`<br>       | 必须是纯 IP，不能填带域名的地址，否则会陷入死循环。                 |
| **代理服务器域名解析**<br>`proxy-server-nameserver` | 解析你机场节点（代理服务器）的域名      | `https://doh.pub/dns-query`<br>`https://dns.alidns.com/dns-query` | 用国内 DoH 最快最稳，防止节点域名被解析到海外绕路导致连不上。           |
| **默认解析服务器**<br>`nameserver`                | 解析日常访问的外网域名            | `https://1.1.1.1/dns-query`<br>`https://8.8.8.8/dns-query`        | **防泄露的核心**。必须填海外加密 DoH，普通上网查询走这里就不会出现国内 IP。 |
| **直连解析服务器**<br>`direct-nameserver`         | 解析走 `DIRECT` 规则的国内域名   | `https://dns.alidns.com/dns-query`<br>`https://doh.pub/dns-query` | 保证国内网站的解析速度，使其不经过海外代理，且不干扰海外解析。             |

---

## 二、 辅助防泄露的“排雷”设置

除了 DNS 覆写，以下设置同样关键：
  - **关闭浏览器自带的 DoH**
    *   在 Chrome/Edge 设置中关闭“使用安全 DNS”，防止浏览器绕过 Clash 偷偷向国内运营商发包。

---

## 三、 遗留问题说明

*   **检测网站偶尔显示 1~2 个国内 DNS 是正常的**：系统后台服务（如时间同步、系统更新）或部分第三方软件可能不走系统代理，直接使用 UDP 53 端口向本地运营商发包。在不开启 **TUN 模式**的前提下，这种情况无法 100% 避免，但**日常上网的网页解析已经绝对安全**，不会暴露真实身份。
*   如果发现大量国内 DNS 泄露，优先检查**浏览器设置变更**是否触发了浏览器重置，或者 `fake-ip-filter` 中是否混入了 `"*"`。
