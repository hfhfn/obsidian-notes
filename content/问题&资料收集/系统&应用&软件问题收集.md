##  1. Clash Party(Mihomo Party)内核错误

- 问题:
    - 内核启动出错 YAMLParseError:Implicit keys need to be on a single line at line 1,column 1: <!DOCTYPE html>
- 解决办法:
    - Win10下解压在非系统盘的便携版，出错后“结束进程树”即可完全正常。试试？ 1、卸载原版本，删除C:\Users\用户名\AppData\Roaming\mihomo-party 文件夹； 2、解压到非系统盘，或复制 data 文件夹到新位置； 3、首次启动，需要以管理员权限运行。

## 2. Windows文件删除异常

- 问题:
    - ms-dos 功能无效, 无法删除
- 解决办法:
    - 把不能删除的文件拖动到dosdel.bat文件上就可以删除
    - dosdel.bat文件内容:
    - ```
        @echo Y|cacls %* /t /e /c /g Everyone:f
         
        DEL /F /A /Q \\?\%1
         
        RD /S /Q \\?\%1
        ```
