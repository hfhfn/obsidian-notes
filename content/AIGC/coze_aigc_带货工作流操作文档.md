## 1. 工作流概览

本工作流以"产品信息"为起点，全自动生成一条 15 秒口播带货短视频，共五个步骤：

```
产品图 + 产品名 + 卖点 + 地区 + 语言
        ↓
  Step 1：AI 生成分镜脚本
        ↓
  Step 2：串联产品图与提示词
        ↓
  Step 3：调用 Seedance 2.0 生成视频
        ↓
  Step 4：轮询视频生成状态
        ↓
  Step 5：输出可用视频链接
```

**核心设计原则：**

- 镜头语言：沉浸式原生短视频风格，高完播率
- 产品还原：材质 / 颜色 / Logo / 细节 100% 一致
- 画面约束：绝对禁止出现任何文字浮层（字幕、水印等）
- 语言适配：口播文案自动匹配目标国家的文化习惯与表达方式

## 2. 输入参数说明

在工作流开始节点配置以下五个输入变量：

| 变量名 | 类型 | 说明 | 是否必填 |
|--------|------|------|----------|
| `img` | 图片文件 | 产品主图（建议白底或场景图） | 否（留空则由 AI 推理） |
| `name` | 文本 | 产品名称，如"便携式挂烫机" | 是 |
| `feature` | 文本 | 核心卖点，如"30秒预热、折叠小巧" | 否（留空则由 AI 推理） |
| `country` | 文本 | 目标国家，如"美国" | 是 |
| `language` | 文本 | 目标语言，如"英语" | 是 |

> **说明：** 若用户未上传产品图或未填写卖点，AI 大模型将根据已有信息自动推理，但建议提供产品图以获得更精准的脚本效果。

## 3. Step 1：生成分镜描述提示词

### 节点类型
大模型节点（LLM Node）

### 角色定位

> 你是一位**全球化短视频内容营销专家**，精通 TikTok、Instagram Reels 和 YouTube Shorts 的爆款底层逻辑。擅长用符合目标国家文化语境的生活化场景和细节展示产品真实体验，镜头语言偏向"沉浸式原生短视频"，助力打造高完播率、真实感产品体验脚本。

### 处理逻辑

1. 提取输入变量：`img`（产品图）、`name`（产品名称）、`feature`（核心卖点）
2. 若 `feature` 为空，则根据产品图和名称自动推理核心体验 / 卖点
3. 读取目标国家（`country`）和目标语言（`language`），自动匹配当地文化习惯
4. 生成一段 **15 秒口播带货短视频分镜脚本**，包含 4 个镜头段落

### 输出格式（String1）

脚本必须严格按照以下五段式结构输出：

```
【人物】<出镜人物描述>
【场景引入】<镜头描述 + 口播文案>
【产品细节】<近景特写描述 + 口播文案>
【真实体验】<使用体验描述 + 口播文案>
【推荐总结】<结尾 CTA 描述 + 口播文案>
```

### 示例输出

**输入：** 产品名称：便携式挂烫机 / 国家：美国 / 语言：英语 / 卖点：30秒预热、折叠小巧

```
【人物】<美国青年上班族白人女性>

【场景引入】<镜头中景，美女单手从旅行包中掏出挂烫机>
口播："Hate wrinkles on trips? This little guy is a lifesaver."

【产品细节】<近景特写，按下开关，蒸汽瞬间喷出>
口播："It heats up in literally 30 seconds. Look at that steam!"

【真实体验】<中景，镜头对准一件褶皱衬衫，快速熨平一半>
口播："One swipe and the wrinkles are gone. It's so satisfying to watch."

【推荐总结】<近景，将挂烫机折叠放回包里，对着镜头点头>
口播："Link is in bio. Grab yours before your next trip!"
```

### 节点输出变量
- `String1`：完整分镜脚本文本

## 4. Step 2：串联产品图与描述词

### 节点类型
大模型节点（LLM Node）

### 处理逻辑

将 Step 1 输出的分镜脚本（`String1`）与产品信息串联，生成用于视频生成模型的**完整视频提示词**。

### 全局约束（必须写入提示词）

| 约束类型 | 要求 |
|----------|------|
| 产品还原 | `{产品名}` 必须严格参照产品图，保持材质、颜色、Logo 和外观细节 100% 一致，禁止改变任何设计 |
| 文字限制 | 画面绝对禁止出现任何字幕或文字浮层（包括中文、日文、韩文、拉丁字母等） |
| 视觉风格 | 电影级摄影，沉浸式原生短视频感 |

### 串联模板

```
介绍 {String2} 的口播视频，电影级摄影。

全局约束：{String2} 必须严格参照产品图，保持产品的材质、颜色、Logo 和外观细节
100% 一致，禁止改变任何设计。画面绝对禁止出现任何字幕或文字浮层（包括日文、
韩文、拉丁字母等）。{String3} 口播。

分镜描述：
{String1}
```

**变量说明：**

| 变量 | 来源 | 内容 |
|------|------|------|
| `String1` | Step 1 输出 | 分镜脚本（五段式） |
| `String2` | 输入变量 `name` | 产品名称 |
| `String3` | 输入变量 `language` | 目标语言（如"英语"） |

### 节点输出变量
- `String4`：串联后的完整视频提示词

## 5. Step 3：调用 Seedance 2.0 生成视频

### 节点类型
插件节点（Plugin Node）— MIVIDEO 插件

### 插件配置

| 配置项 | 值 |
|--------|-----|
| 插件名称 | MIVIDEO |
| 生成模式 | 慢速版（Slow Mode） |
| 输入提示词 | `String4`（Step 2 输出） |
| 参考图片 | `img`（用户上传的产品图） |

### 操作步骤

1. 在 Coze 工作流中添加**插件节点**
2. 搜索并选择 `MIVIDEO` 插件
3. 选择视频生成动作，模式选择**慢速版**
4. 将 `String4` 绑定到提示词输入字段
5. 将产品图 `img` 绑定到参考图输入字段（若支持图生视频）
6. 执行后获取任务 ID（`task_id`）

### 节点输出变量
- `task_id`：视频生成任务唯一标识

## 6. Step 4：查询视频生成状态

### 节点类型
插件节点（Plugin Node）+ 条件判断节点（Condition Node）

### 处理逻辑

通过轮询机制持续查询视频任务状态，直到任务完成或失败。

**状态枚举：**

| 状态值 | 含义 | 下一步操作 |
|--------|------|------------|
| `processing` | 生成中 | 等待后重新查询 |
| `success` | 生成成功 | 进入 Step 5 |
| `failed` | 生成失败 | 返回错误信息，建议重试 |

### 节点配置

```
输入：task_id（来自 Step 3）
查询间隔：建议 10～30 秒
最大轮询次数：建议不超过 20 次（约 5～10 分钟）
```

### 条件分支设置

```
IF status == "success"  → 进入 Step 5
IF status == "failed"   → 输出错误提示，结束流程
IF status == "processing" AND 轮询次数 < 最大次数  → 等待后继续查询
IF 超过最大轮询次数  → 输出超时提示
```

### 节点输出变量
- `video_status`：当前任务状态
- `video_url`：视频地址（仅 `success` 状态时有值）

---

## 7. Step 5：输出有效视频地址

### 节点类型
结束节点（End Node）/ 消息输出节点

### 输出内容

当视频状态为 `success` 时，输出以下信息：

```
✅ 视频生成成功！

产品名称：{name}
目标国家：{country}
目标语言：{language}
生成模型：Seedance 2.0 慢速版

🎬 视频地址：{video_url}
```

### 注意事项

- 输出的 `video_url` 为**有效期内的直链地址**，请及时下载保存
- 建议将链接同步至素材库或 CDN，避免链接失效

## 9. 注意事项与常见问题

### 9.1 产品还原问题

**问题：** 生成的视频中产品外观与实际不符

**解决方案：**
- 上传清晰的产品主图（建议分辨率不低于 800×800px）
- 在提示词中强调品牌色、Logo位置等关键细节
- 使用图生视频模式（参考图输入）而非纯文字生成

### 9.2 视频生成超时

**问题：** 轮询超过最大次数仍未完成

**解决方案：**
- Seedance 2.0 慢速版平均生成时间约 3～8 分钟，请适当延长轮询等待
- 检查提示词长度，避免过于复杂导致生成延迟
- 在高峰期可适当增加最大轮询次数至 30 次

### 9.3 口播语言不自然

**问题：** 生成的口播文案不符合目标国家表达习惯

**解决方案：**
- 在卖点字段中填写具体的使用场景，而非单纯的产品参数
- 明确指定目标平台（TikTok / Instagram），不同平台语气有差异
- 如有条件，可在 Step 1 后增加一个人工审核 / 编辑节点

### 9.4 画面出现文字

**问题：** 视频中出现了字幕或文字浮层

**解决方案：**
- 确认 Step 2 的串联提示词中包含"禁止文字浮层"的全局约束
- 在提示词结尾追加强调：`no text, no subtitles, no watermark, no overlay`

### 9.5 视频链接失效

**问题：** 输出的 `video_url` 无法访问

**解决方案：**
- Seedance 生成的视频链接通常有时效限制，请在生成后 **24 小时内** 下载
- 建议在工作流末尾增加一个**自动下载 / 转存到云存储**的节点
