## 📌 摘录（核心概念）

**MCP（Model Context Protocol，模型上下文协议）** 是连接 LLM 与外部系统的标准协议。

| 概念 | 说明 |
|------|------|
| **协议规范** | 定义客户端/服务器通信规则、数据格式、请求响应结构、错误处理 |
| **MCP 客户端** | LLM 端实现，负责构建请求发给服务器（Anthropic 提供 Python/TS/Java SDK） |
| **MCP 服务器** | 外部系统端实现，接收请求、与数据源交互、按协议返回数据 |
| **上下文信息交换** | 促进 LLM 与外部系统的上下文双向交换 |
| **能力协商** | 通信开始时确定双方支持的功能与协议版本 |
