# Agent 跨会话长期记忆：五问架构

本题拆解大厂高频面试题——Agent 如何在跨会话中管理长期记忆。从记忆分类、写入时机、检索策略、上下文压缩到评测方法，五问串联一套可落地的记忆系统架构。

---

## 一、记忆分三类，少一类就露馅

| 类型 | 说明 |
|------|------|
| **短期记忆** | 当前一轮对话的上下文，来得快去得快，窗口关闭即消失 |
| **长期记忆** | 跨会话保留，下次开新窗口还能调用，包括用户偏好、事实和重要事件 |
| **工作记忆** ⚠️ 最容易被漏掉 | Agent 干活过程中的中间状态：查过哪些资料、调过什么工具、任务走到第几步 |

- **工作记忆缺失的后果**：一个十步的长任务，跑到第七步就把前六步忘了，直接原地打转。
- 三者能分清，面试官就知道你不是纸上谈兵。

---

## 二、何时写、怎么写：三条写入路径 + 冲突检测

看的不是频率，是**时机和信号**。工程上常用三条路径：

### ① 会话结束后统一抽取
聊完后一次性抽取结构化记忆，而非把整段聊天原样丢进库里。
> 示例："下周我要去东京出差" → 抽取为三项：事项=出差、时间=下周、地点=东京。

### ② 事件触发立刻写
最高优先级信号当场落库，不等总结。
> 示例：用户说"我对芒果过敏" → 立刻存。

### ③ 空闲时段后台整理
零散记忆归并去重、合并同类项。

### 加分项：冲突检测
旧记录不是简单追加一条新的，而是**更新原记录**，打上新时间戳，避免两条打架的记忆同时被召回。
> 示例：库里有"三年前爱喝全糖拿铁" + 新记录"去年改空糖" → 应更新并打时间戳，而非并列两条。

## 三、检索不能只看向量相似度：组合拳策略

只靠语义相似度要吃亏，需叠加多层加权：

| 层次 | 策略 |
|------|------|
| **底子** | 语义相似度 |
| **叠加① 时间衰减** | 越久远的记忆权重越低；去年的偏好不应等于三年前的权重 |
| **叠加② 重要性加权** | 过敏源等关键信息与"想看场电影"不能等同 |
| **叠加③ 混合检索** | 关键词检索 + 向量检索双路召回 |

混合检索的目的：人名、型号、编号等专有名词不会被语义稀释掉。

> 核心结论：好的记忆检索找的不是"最像的"，是**此刻最该想起来的**。

---

## 四、上下文分层压缩：让上下文学会呼吸

外部记忆再强，窗口还是有限的，需分层处理：

| 层级 | 处理方式 |
|------|----------|
| 最近几轮 | 原文保留，一字不改 |
| 更早的几轮 | 压成一段摘要 |
| 更早的 | 浓缩成一条记忆转存长期库 |

### ⚠️ 常见翻车坑
- **关键约束和关键数字必须原样锚定到系统提示词**，压缩一律不碰。
- 一旦压丢，Agent 就会一本正经地编造。
- 典型翻车现场：报销上限"5000元"被压缩后丢失，Agent 输出"50000元"。

## 五、验证机制：该忘的要忘，还得能考出来

### ① 记忆的淘汰逻辑
- 长期没人检索的记忆 → 降权、淘汰
- 被新事实推翻的记忆 → 更新/淘汰
- 价值很低的记忆 → 降权、淘汰
- 否则记忆库越滚越大，检索质量反而下降

### ② 隔天考卷法
今天告诉它的事，明天换个问法再问一遍，检验三件事：
- 记没记住
- 记没记错
- 不该记的有没有忘

### ③ 业界评测集维度
已有专门的**长程记忆评测集**，考查五件事：
- 信息提取
- 跨会话推理
- 知识更新
- 时间推理
- 该拒答时拒答

能说出"记忆也要做评测"，面试官印象会完全不同。

## 速查：五问对应关系

| 问题 | 核心结论 |
|------|----------|
| 记忆分几类 | 短期 / 长期 / 工作记忆，三类缺一不可 |
| 何时写 | 会话后抽取 + 事件触发即时写 + 空闲后台整理 |
| 如何写 | 旧记录更新而非追加，打时间戳防冲突 |
| 怎么检索 | 相似度打底，叠加时间衰减、重要性加权、混合检索 |
| 窗口有限怎么办 | 最近轮原文保留，更早摘要化，最早转长期库 |
| 怎么验证 | 隔夜换问法重测 + 长程记忆评测集（提取/推理/更新/时间/拒答） |

## 面试真正在考什么（五问归三）

| 维度 | 含义 |
|------|------|
| **① 结构化思维** | 先分类，再动手，别拿"向量数据库"六个字顶到底 |
| **② 踩坑经验** | 冲突怎么更新？压缩会丢什么？检索为什么不能只看相似度？ |
| **③ 闭环意识** | 记住了不算完，得能验证——记得对不对、该忘的是否真忘了 |

> **分水岭**：背八股的人答"记忆是什么"，跑过项目的人答"记忆怎么不翻车"。
