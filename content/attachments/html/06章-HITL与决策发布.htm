6.9–6.10 连续流：HITL 暂停 → 教师决策 → 发布

中断机制（interrupt / Command(resume) / MemorySaver）与决策发布（approve-modify / 三分数）一条线讲完

连续流主线：⑦ teacher_review interrupt() 暂停（图冻结，State 存 MemorySaver）→ 教师 GET /{id}/review 用 aget_state 读 AI 预批改 → POST /confirm 传 Command(resume=decision) → ⑦ 恢复，interrupt() 返回 decision → ⑧ 按 approve / modify 合并 → publish_results 写库 → END。

三分数：ai_score 永久保存；teacher_score 仅 modify 有；final_score = approve 取 ai、modify 被改题取 teacher、未改取 ai。

interrupt 机制 5 步：① interrupt(value) 抛内部 Interrupt；② ainvoke 捕获并存 State 到 MemorySaver；③ ainvoke 真正返回；④ 图暂停（next=[teacher_review]）；⑤ Command(resume) 恢复，让 interrupt() 返回 decision，图从原处继续。

⚠️ 编译图不传 interrupt_before，只在节点内调 interrupt()（LangGraph 1.0 新写法）。
