# 🎬 视频与专题

> YouTube / B 站视频的 NotebookLM 笔记。每条包含视频源、摘要，以及生成的思维导图、演示文稿、信息图等衍生笔记。

## 📝 关于这个栏目

每条笔记对应 NotebookLM 里的一个笔记本，通常包含：

| 类型 | 说明 |
|---|---|
| **视频源** | YouTube / B 站原视频链接 |
| **摘要** | NotebookLM 基于视频生成的正文摘要 |
| **思维导图** | XMind / Mind Map，梳理视频脉络 |
| **演示文稿** | PPT 幻灯片，适合快速过一遍 |
| **信息图** | 单页长图，适合分享 |

### 一条笔记怎么写

```yaml
---
title: 视频标题
source_url: https://www.youtube.com/watch?v=xxx
platform: youtube          # youtube / bilibili
duration: 42分钟
channel: 频道名
cover: 封面图 URL
status: 已整理              # 已整理 / 待整理 / 整理中
progress: 100
created: 2026-11-08
tags:
  - video
---
```

正文写你的摘要与收获。衍生的思维导图 / PPT / 信息图放在
`视频与专题/<标题>/` 子目录里，或直接上传到 `attachments/` 后用
`[[...]]` 链接引用。

### 字段说明

- `source_url` — 原视频链接，卡片上会显示「看原视频」按钮
- `platform` — 决定卡片上显示 YouTube 还是 B 站图标
- `derived` — 衍生笔记类型列表，如 `[mindmap, slides, infographic]`，
  卡片上会显示对应角标
